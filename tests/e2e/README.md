# E2E Tests

This directory contains CLI-driven end-to-end tests for `btxmlc`.

The tests cover:

- `btxmlc format`
- `btxmlc format --check`
- `btxmlc format --check --diff`
- `btxmlc lint`
- `btxmlc check`
- `btxmlc dump-model`

Fixtures live under `tests/e2e/fixtures/` and snapshots under `tests/e2e/snapshots/`.
