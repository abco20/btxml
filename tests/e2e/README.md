# E2E Tests

This directory contains CLI-driven end-to-end tests for `btxml`.

The tests cover:

- `btxml format`
- `btxml format --check`
- `btxml format --check --diff`
- `btxml lint`
- `btxml check`
- `btxml dump-model`

Fixtures live under `tests/e2e/fixtures/` and snapshots under `tests/e2e/snapshots/`.
